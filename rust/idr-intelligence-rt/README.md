# idr-intelligence-rt

Rust serving bridge for `idr-intelligence` ONNX export bundles (W17). It reads
newline-delimited JSON in the wire format serialized by `idr_common::IdrEvent`,
carries per-entity S6 state through the exported `step.onnx` cell, scores the
entity graph with `head.onnx`, and prints a finding that matches the Python
`StreamingScorer` field-for-field. Inference runs on
[tract](https://github.com/sonos/tract) — pure Rust, no ONNX Runtime library.

```sh
# On the Python side, once per model:
idr-intelligence export --weights artifacts/hybrid_model.pt --out artifacts/export

# Then score a stream without Python:
cargo run --release -- --model-dir artifacts/export events.ndjson
cat events.ndjson | cargo run --release -- --model-dir ../../artifacts/export --max-nodes 64
```

Every constant scoring needs — prior tables, ATT&CK mapping, calibration,
dimensions, IO signatures — is read from the bundle's `manifest.json`, so the
Python exporter stays the single source of truth.

## Parity

`tests/` pins this port to the Python engine through committed fixtures
generated by `tests/fixtures/generate.py`:

- `feature_vectors.json` — per-event entities, edges, and feature vectors from
  `features.project_event`, asserted exactly.
- two golden streams (`events_*.ndjson` + `expected_*.json`) scored by the
  torch `StreamingScorer`; the Rust finding must agree on every discrete field
  and be within `1e-4` on probabilities and drift.

The machine-local crate `../idr-common-parity` additionally proves the input
side against the real `idr_common` types from the idr-main tree.

## Deliberate scope (mirrors Python streaming)

- `entity_evidence` is always empty — occlusion attribution needs history
  replay, which streaming exists to avoid.
- `campaign_id` uses the first-event fallback; the cross-window
  `CampaignRegistry` stays on the Python side (`continues_campaign` false,
  `windows_observed` 1).
- Events must arrive in chronological order; the CLI sorts its whole input,
  a long-running consumer owns its own reorder buffer.

Findings are advisory: the evidence boundary in `docs/ARCHITECTURE.md` applies
unchanged — output feeds the deterministic IDR correlator for corroboration
and must never trigger an automated response on its own.
